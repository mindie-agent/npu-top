# MindIE NPU Top (`npu-top`) brand assets

The telemetry-bars Agent mark (diamond Agent head over five symmetrical vertical utilization bars) identifies `npu-top` within the MindIE Agent brand family.

- `npu-top-logo-source.png`: 1254 × 1254 master transparent PNG.
- `npu-top-logo.png`: 512 × 512 transparent PNG for repository READMEs and avatars.
- `npu-top-icon.png`: 128 × 128 compact transparent PNG for UI icons.
- `PROMPT.md`: generation prompt and visual family reference.

Brand accent: `#7045F5` (aligned to the parent [`mindie-agent`](https://github.com/mindie-agent/mindie-agent/tree/main/assets/brand) tile and alpha mask). The same high-contrast mark works on light and dark backgrounds. Preserve its aspect ratio and transparent outer margin.
